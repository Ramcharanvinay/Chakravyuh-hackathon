## 🌟 Overview

**CHAKRAVYUH** is the official site of the 48-hour national hackathon at **VIT-AP University**. It presents the event, the five battle gates, and **all 50 problem statements** in full, so every team can read them and choose the challenge they want to build.

It is a **static, read-only website**. There are no accounts, no logins, no team registration and no database. Registration happens on **Unstop**, and teams tell the organizers which problem they picked through the organizers' own **Google Form**.

- **CAD-style 3D gate models**: five procedural Three.js models, one per gate (server rack and hash-linked blocks, communications satellite, dilution refrigerator, payment devices, spinning wind turbines), with crisp edge lines and labelled callouts.
- **50 problem statements** across 5 tracks, each with objective, deliverables, public datasets and a suggested tech stack.
- **Cinematic landing page** with the rules, prize pool, partners, clubs and venue.
- **Fast and cheap to host**: it is plain static files, so there is nothing to configure, secure or scale.

## 🔄 How Teams Use the Site

```mermaid
flowchart LR
    A["Register on Unstop"] --> B["Open the site"]
    B --> C["Explore the 5 battle gates<br/>(3D models)"]
    C --> D["Read the 10 problem statements<br/>of a gate in full"]
    D --> E["Choose a challenge<br/>(the team's own decision)"]
    E --> F["Tell the organizers<br/>via the Google Form"]
```

- There is nothing to sign in to and nothing is locked on the site. Teams can read any gate, as many times as they like.
- The organizers collect each team's choice through their Google Form. If you set the form link (see below), a **"Submit your choice"** button appears in the header, on the landing page and under each gate's problems.
- Old links such as `/login`, `/submit` and `/problems` simply redirect to the site.

## 🎨 3D Gate Models

Five procedural Three.js models (`buildCyberGate`, `buildSpaceGate`, `buildQuantumGate`, `buildFintechGate`, `buildEnergyGate` in `src/components/gateModels.ts`):

- **Cybersecurity & Blockchain**: a 42U server rack with a brass padlock and hash-stamped blocks joined by interlocking chain links.
- **Space Technology**: a communications satellite with a parabolic dish, horn cluster and sun-tracking solar arrays.
- **Quantum Computing**: a dilution refrigerator labelled with its stage temperatures (300 K down to 10 mK) and a transmon chip.
- **FinTech**: a payment phone with a live UI, EMV cards, reeded ₹ coins and a candlestick chart.
- **Energy & Sustainability**: wind turbines with airfoil blades that spin, a solar array and a battery container.

Each has drafting-style edge lines and labelled callouts, is lit by a simulated HDRI environment, and responds to orbit controls and touch gestures.

## 🛠️ Developer Quickstart

### Prerequisites
- **Node.js** `v18` or higher (tested on Node 20 and 24)
- `npm`, `pnpm` or `yarn`

### Run it

```bash
git clone https://github.com/Ramcharanvinay/Chakravyuh-hackathon.git
cd Chakravyuh-hackathon
npm install
npm run dev
```

The site opens at `http://localhost:5173`. There is no database or environment setup needed.

### Build for production

```bash
npm run build      # outputs static files to dist/
npm run preview    # serve the production build locally
```

### Deploy

It is plain static hosting. On **Vercel** (or Netlify) import the repository, leave the defaults (`npm run build`, output `dist`) and deploy. `vercel.json` already rewrites every path to `index.html` so deep links such as `/theme/fintech` work.

---

## 📝 The "Submit your choice" button (optional)

When your Google Form is ready, either:

1. Set the environment variable `VITE_CHOICE_FORM_URL` to the form link (in Vercel: **Project Settings → Environment Variables**, then **redeploy**, since the value is baked in at build time), **or**
2. Paste the link into `choiceFormUrl` in [`src/config/hackathonConfig.ts`](./src/config/hackathonConfig.ts).

While it is empty, no button is shown anywhere.

## ⚙️ Editing the Event Content

Everything about the event lives in one file: [`src/config/hackathonConfig.ts`](./src/config/hackathonConfig.ts): college and hackathon names, dates, contact email, the five tracks and all 50 problem statements (title, summary, objective, full description, deliverables, datasets, tech stack, difficulty).

Landing-page text (rules, prizes, sponsors, venue) is in `src/components/landing/`.
